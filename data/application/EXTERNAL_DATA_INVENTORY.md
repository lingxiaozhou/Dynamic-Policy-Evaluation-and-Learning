# Application Data Inventory

The application code uses district-level Iraq data. It requires two local external files and rebuilds all other inputs from fixed Harvard Dataverse file IDs or package datasets.

## Required local inputs not currently distributed

- `Maaws_PublicData.csv`: CERP/aid project data used to construct district-day and district-week treatment indicators.
- `final_filter.csv`: district-level troop-density source table used when constructing `tf_array_US` and `tf_array_US_missing`.

These are the only local source files expected by `R/application/run_application_analysis.R`. They are intentionally excluded from this repository while permission to make them public is being confirmed. Until that determination is complete, readers can inspect the application code and the included saved results, but cannot rebuild the complete application dataset from the repository alone.

Generated application RDS files are also intentionally not distributed because they contain detailed data derived from these restricted inputs and the Dataverse sources.

## Harvard Dataverse 4.0 inputs

The script downloads these fixed file IDs from `https://dataverse.harvard.edu`:

| Object used in code | File ID | Purpose |
|---------------------|---------|---------|
| `iraq_district` | `8138903` | district boundary shapefile object |
| `cities_dist` | `8079278` | district distance to cities |
| `rivers_dist` | `8079275` | district distance to rivers |
| `routes_dist` | `8079274` | district distance to routes |
| `ethnicity` | `8079276` | district ethnic-group covariates |

The helper `read_dataverse_rds()` downloads each file to a temporary location and reads it as an RDS object.

## Package datasets

The workflow also uses these datasets from the `geocausal` package:

- `airstrikes`
- `insurgencies`
- `airstrikes_base`
- `iraq_window`

The public application code was checked with `geocausal` version `0.3.4`.

## Generated files not distributed

The following files are generated by `R/application/run_application_analysis.R` and are not required source inputs. The RDS files are retained locally when produced, but are excluded from the repository because they contain detailed application data:

- `application_data.rds`
- `prepared_application_data.rds`
- `iraq_district_sf.rds`
- `propensity_score_diagnostics.rds`
- `outputs/results/res_SAF_wopop.dat`
- `outputs/results/res_IED_wopop.dat`
- `outputs/results/res_SAF_wpop.dat`
- `outputs/results/res_IED_wpop.dat`
- application plots under `outputs/plots/application/`
